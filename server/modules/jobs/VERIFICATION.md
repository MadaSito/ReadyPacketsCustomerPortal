Lost external effects remain unknown. An administrator can attest that they independently reconciled the job after review, but the durable job remains unknown. The queue never retries that job; mail alone can be queued as a separate generation after fresh verification and explicit acknowledgement of the duplicate risk. Claims, heartbeat, fencing checks and reaping use the shared MySQL UTC clock for lease validity; scheduling and audit timestamps still use the application clock. Outbox expiry is enforced before SMTP, resend and capture access; bounded deletion waits for a running, non-draining worker.
