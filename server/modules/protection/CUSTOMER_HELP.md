# If the portal blocks a request

If you see a security message, note the reference ID and the time. Contact your usual support channel and include that reference and what you were trying to do. Do not send your password, verification codes, cookies, or payment information.

If the portal says you sent too many requests, wait for the stated retry time before trying again. Avoid repeatedly refreshing or resubmitting a payment; if you are unsure whether it went through, ask support to check before sending it again.
