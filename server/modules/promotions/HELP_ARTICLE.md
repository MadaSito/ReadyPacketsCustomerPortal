# Using a discount code or promotional link

Customer help article draft (increment 05, promotions). Owner: `siem_engineer`.

## Applying a discount code

When discount codes are enabled on the portal, you can apply a code in either **Cart** (`/cart`) or the **New order** wizard (`/orders/new`):

1. Make sure your account e-mail address is verified.
2. Enter your code in the **Discount code** box and select **Apply**. Codes are not case-sensitive.
3. Review the updated summary before placing your order. Your order and invoice display the promotion's descriptive label rather than the code itself.

## Opening a promotional link

If you received a ReadyPackets link such as `/promo#promo=...`:

- Opening the link saves the code in your current browser session and displays **"Code saved — it is applied when you place an order."**
- The saved code stays available while you sign in or finish creating your account during the same browser session, and is offered automatically when you visit your cart or start an order.
- A link never places an order or applies charges automatically — you always review and confirm the final total before submitting.

## How discounts are calculated

- **Bundle and promotional discounts**: unless a promotion is marked as combinable with bundle discounts, you automatically receive whichever single discount saves you more.
- **Discount kinds and portal limits**: codes may take a percentage off (up to two decimal places), take a fixed currency amount off, or set the pre-tax order total to a specific amount (including zero-total orders when permitted by portal policy). If a code exceeds an active portal discount limit, the portal explains which limit prevented it from applying.
- **Eligible items and minimum subtotal**: some codes apply only to specific packets, tiers, or products, or require a minimum pre-tax subtotal.
- **Tax**: applicable tax is calculated on the discounted subtotal.
- **Price changes before submission**: if a code expires or reaches its redemption limit before you submit your order, your order is not placed automatically — you will be asked to review and confirm the updated total first.
- **Cancellations and refunds**: if an order is cancelled with no open invoice before any online payment attempt or payment is made, its code redemption is released. Once an online payment attempt or payment has occurred (including orders that are later refunded), the code redemption remains used.
