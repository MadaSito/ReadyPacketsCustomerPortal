# Work with customer phases

Open an order in the console, choose **Phases**, and select a named phase. The panel shows whether the phase is open, submitted, under review, complete or reopened. It also shows the time of submission and the latest review, when available.

## Assign and review questions

- **Assign question:** Enter the text the customer should see. Mark it required only if the customer must answer before moving on. Do not request passwords, sign-in codes or other authentication secrets.
- **Answer history:** The phase shows the latest answer. Choose **Show answer history** to inspect earlier saved versions; editing never replaces the previous version. A withdrawn question stays in the console with its answer history but is no longer shown to the customer.

## Review a submission

- **Accept submission:** Record the review with an optional note. Use **Request changes** to explain what the customer needs to change. That action records the review but does not reopen editing.
- **Reopen phase:** An administrator enters a reason, confirms the change, and verifies their identity if prompted. Reopening allows the customer to edit the phase again. The reopen reason is recorded for staff.
- **Administrator checklist:** Check or uncheck items to track work. The panel records who checked an item and when, and audits both changes. Checking an item does not substitute for accepting a submission, uploading a document, or running phase actions.
