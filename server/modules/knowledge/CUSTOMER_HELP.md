# Using the Knowledge Base (`/help`)

When enabled by your administrator, **Support → Knowledge base** (`/help`) provides step-by-step guides, packet preparation checklists, and answers to common questions.

## Finding Answers

- **Search**: Enter keywords in the search bar on `/help`. Results rank title and tag matches first and highlight matching terms in titles and excerpts.
- **Browse by topic or tag**: Select any topic card (`/help/categories/:slug`) or tag chip to filter guides. If a search finds no exact matches, suggested topics, popular guides, and a direct **Open support ticket** link are shown.
- **Contextual help when opening a ticket**: While typing a subject or description on **Support → New ticket** (`/support/new`), matching guides appear automatically so you can resolve common questions right away.

## Reading, Printing, and Downloading Checklists

- Each guide (`/help/articles/:slug`) includes an **On this page** section outline, last-reviewed date, **Print article** action, and downloadable attachments where provided.
- At the bottom of any guide, select **Yes** or **No** under **Was this article helpful?** to share feedback with the documentation team.
