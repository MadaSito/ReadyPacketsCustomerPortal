# Upload files or record audio for an order

Open the order's Files tab. If a requirement is waiting for a file, choose it in Upload to. A general upload does not satisfy a workflow requirement. The form shows the allowed formats and limits; only people authorized to view the order can access files in a workflow slot. If access has changed or the order is locked, contact your ReadyPackets team.

Choose Record where the order or task allows recording. Check microphone lets you choose a microphone, see its signal level and play a five-second test that never leaves your device. Then select Start recording and respond to your browser's permission prompt. Pause, resume, stop and listen before choosing Use this recording. The recording stays on your device until you press Upload file.

If the browser cannot record, use Record with your device. Some phones open a capture control; other devices open a file picker. You can also choose an existing audio file when the task allows uploads. Include a plain-text transcript so readers who cannot listen can still use the information.

After upload, the order shows the WebM/Opus copy when it is ready. The server re-encodes audio into that format; it is not bit-identical to the original. A failed conversion does not remove the original. Use Listen to load the recording and any supplied transcript, or download the file for playback outside the browser.

If Edit document is available for a Word file, saving your changes creates a new file version and leaves the original intact. You may need to accept the order agreement before saving a recording, upload or document edit.
