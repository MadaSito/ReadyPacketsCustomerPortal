# ReadyPackets Portal

Self-hosted customer portal, staff workspace and administration console for ReadyPackets
(`https://my.readypackets.com`). Secure rebuild from the specifications in `docs/source-specs/`.

- Engineering contract: `docs/engineering/BUILD_CONTRACT.md`
- Application context: `docs/application-context/`
- Session logs: `docs/session-logs/`

Status and verification evidence are tracked in `docs/application-context/` — nothing in this repository
should be read as a certification or a guarantee of security.
