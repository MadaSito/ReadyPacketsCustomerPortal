# Help article (draft): Using a discount code when you place an order

If you have a discount code, you can use it in the last step of **Create an order**.

1. Choose your items and enter your project details.
2. In **Review**, type the code in **Discount code** and select **Apply**. The new total is shown and read out by screen readers.
3. Select **Submit order**. The discount is fixed on your order.

The same code field appears in your cart when the cart is used.

## Good to know

- One code per order. Codes are not case-sensitive.
- If a code cannot be used, you will see "This code cannot be applied." For your security, we do not say why. Check the code, or contact us.
- If you change your items after applying a code and it no longer applies, the code is removed and you are told. Apply it again if your items change back.
- If a code expires or runs out just before you submit, the order is not placed. Review the new total and submit again.
- After several unsuccessful tries, code checks are paused for a few minutes.
- If you cancel an order before paying, the code may become available again. A refund does not make the code available again.
- When our team creates an order for you, they can apply a code that is valid for your account.
