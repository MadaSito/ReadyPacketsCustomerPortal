## Response and results

Fourteen engineering packages (A–P) delivered the fifteen items under [INCREMENT_06_CONTRACT.md](../engineering/INCREMENT_06_CONTRACT.md).

**Defaults.** Features that are safe and need no configuration are on after upgrade. Policy enforcement, the MNDA gate and cart suggestions stay off until the owner configures them. The admin guide's "Where to switch things on" table lists every switch and its page.

### What was built

| Item | Result |
| --- | --- |
| 1 | Navy side panel with a stronger active state in both themes. |
| 2 | Record button and preflight. The browser records in its best format, and the server converts to WebM/Opus. This is a high-quality re-encode, not bit-identical; the original is kept as the lossless record ([ADR 0047](../adr/0047-recording-and-preflight.md)). |
| 3 | Starter suggestions seeded from the catalogue, all disabled, with a master switch, per-row switches and Enable all. |
| 4 | Installable app with install steps for each platform, and a service worker that caches only public static files ([ADR 0048](../adr/0048-pwa.md)). |
| 5 | Limits card: percentages up to 100 % with two decimals, plus the "Set order total to" kind for $0.00 and $0.01. Stripe refuses card charges below its minimum (0.50 USD), so such amounts are waived by default or can be blocked. |
| 6 | Eight built-in reports and whitelisted custom reports with step-up CSV ([ADR 0049](../adr/0049-reports.md)). |
| 7 | Automatic sign-in bans with lock-out guards, rate-limit back-off and correlated incidents sent to the SIEM ([ADR 0050](../adr/0050-signin-bans-backoff-correlation.md)). |
| 8 | Customer tasks per status (upload, acknowledge, record, respond to a document) with type restrictions ([ADR 0051](../adr/0051-phase-tasks.md)). |
| 9 | Word editing in the portal. Each save is a new version and the original is kept. Headers, footers, tracked changes, comments, text boxes, footnotes, complex fields and exact layout are not kept ([ADR 0052](../adr/0052-word-editing-in-portal.md)). |
| 10 | Workflow export and import is on, with Export selected and Export all. |
| 11 | Typed name checked against the account name. |
| 12 | Policy import from Word, Markdown or PDF (PDF as text only), and a timed notice with a countdown and "Send now". |
| 13 | Enforcement with a custom warning and grace period, then session end and `/accept-policy` ([ADR 0053](../adr/0053-policy-notices-and-enforcement.md)). |
| 14 | Order agreement (MNDA) gate, configurable on the Policies page. |
| 15 | Branded receipts, e-mailed and listed in the portal ([ADR 0054](../adr/0054-receipts.md)). |

### Defects found in QA and fixed before merge

- **Receipts deep link:** fixed to `/invoices?tab=receipts` (`36a486e`).
- **Checkout dead end:** checkout stopped when the gate policy used a typed name (`8243000`).
- **Tick box shown for a typed-name gate:** `/accept-policy` and the prompt offered only a tick box when the gate required a typed name (`672e900`; UI feedback `7a39164`, `4810201`).
- **Prompt re-opening:** the policy prompt re-opened on every navigation after "Later" (`39fb16e`).
- **Notice copy:** singular and plural (`7a39164`).
- **CodeQL on PR #13:** two findings at or above the gate were fixed before merge: table-cell escaping in the document importer and a check-then-read race on the brand logo file (`a10cc50`, with an escape-aware table reader shared by the policy renderer and the Markdown importer). Policy links now also refuse backslash-prefixed paths (`d14a34c`). All four workflows (ci, security, container, native-install) passed at `d14a34c`.
- **Test timeouts:** hardened (`0e63c94`, `4614c02`).
- **Layout and focus:** the PageHeader wrap and the install dialog focus (`751fccc`, `80af96e`).
