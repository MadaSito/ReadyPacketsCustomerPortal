## Decisions and evidence boundaries

- **Mail preview:** UI Foundation and package M approved a tokenless sandboxed `srcdoc` with a fixed CSP meta as the first item in the head and a server-produced semantic HTML projection that removes navigation and network sinks. The global CSP does not change. Text-only display is safe; the Jobs message dialog displays HTML source as text. The template preview still needs browser verification under the standard policy.
- **OAuth callbacks:** The redirect boundary includes the reverse proxy, not just Express. Canonical callback paths must not forward credentials or state to aliases or plain HTTP; URL queries must not appear in access logs. Verify native and container edge behavior separately from the application route.
- **Coverage:** This ledger does not certify the build or provider interoperability. Review of OIDC/Assurance, provider adapters, automation action enforcement and browser CSP remains in progress.
- **HTTP baseline:** `scripts/dev/test.sh tests/http/app.test.ts` passed 21 tests. The scoped HTTP/security typecheck reported no matching diagnostics; neither command verifies live provider behavior.
