## Decisions and evidence boundaries

- **Mail preview:** UI Foundation and package M approved a tokenless sandboxed `srcdoc` with a fixed CSP meta as the first item in the head and a server-produced semantic HTML projection that removes navigation and network sinks. The global CSP does not change. Text-only display is safe; the Jobs message dialog displays HTML source as text. The template preview still needs browser verification under the standard policy.
- **OAuth callbacks:** The redirect boundary includes the reverse proxy, not just Express. Canonical callback paths must not forward credentials or state to aliases or plain HTTP; URL queries must not appear in access logs. Verify native and container edge behavior separately from the application route.
- **Coverage:** This ledger does not certify the build or provider interoperability. Review of OIDC/Assurance, provider adapters, automation action enforcement and browser CSP remains in progress.
- **HTTP baseline:** `scripts/dev/test.sh tests/http/app.test.ts` passed 21 tests. The scoped HTTP/security typecheck reported no matching diagnostics; neither command verifies live provider behavior.
- **Independent regression runs:** `scripts/dev/test.sh server/modules/jobs/jobs.test.ts` passed 36 tests; `scripts/dev/test.sh server/modules/audit/tap.test.ts` passed 20 tests.
- **Host recovery:** `scripts/dev/test.sh scripts/ops/recover-admin.test.ts` passed 3 tests, including atomic recovery, one session revocation count and no local-MFA bypass. The TTY/Docker wrapper itself was not run.
- **Storage writes:** Individual wrapper runs passed 4 Dropbox/Drive adapter, 6 S3/Azure object adapter, 16 Graph drive adapter and 5 Graph port tests with fakes. Storage core passed 10 tests including scoped automation staging.
- **Storage OAuth handoff:** 10/10 MySQL/HTTP tests passed after egress registration on `4a55347`, including the production policy implementation with synthetic DNS and HTTPS. Browser completion and external provider interoperability were not exercised.
- **Central egress:** Integrations 10/10 passed. Source inspection verified public-address checks across DNS answers for the cloud purposes, an administrative allowlist and address pinning; the guarded Drive `PUT` 308 is treated as upload status, not followed as a redirect. These tests do not prove Graph dispatch wiring.
- **Identity/Assurance:** Identity 49/49 and Assurance/Identity integration 1/1 passed. SSO 36/36 passed after fixing eight fixtures, including the preview refusal, seven invalid-token refusals and three configuration races. The independent SSO HTTP suite passed 3/3 using a fake IdP and MySQL; it checks application callback behavior, not a deployed proxy.
- **Mail HTML review:** Normal AST text and dynamic URL/alt values are escaped; attributes are quoted and structural table values are finite enums or bounded integers. URL attributes are entity-decoded before trimming and validation with `URL`; approved schemes are `https:` and `mailto:` for links and only `https:` for images. Preview removes navigation and network sinks. The JSDOM suite passed 6/6 through `3ca7195`, including 150 deterministic mixed-nesting cases and the final cap/idempotence regressions; JSDOM does not verify browser CSP.
